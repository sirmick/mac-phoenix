# QuickTime calls per application (traced, ROM machine)

Generated by tools/qt/qt_calls.py SNAPSHOT --app APP --direct --resolve --markdown from snapshots taken with --trace-atraps on the Quadra 650 (UAE). "direct": calls from the application's own code (outside the System heap and ROM, not at interrupt time, not inside another QuickTime call); "nested": the same routine called by QuickTime or the System meanwhile. Component calls name the 'thng' code the instance ran and the Universal Interfaces names that fit (paramSize, what). HyperCard's calls on the instance resolved as "Color SW Pro 'CODE' -8191" are AppleScript/OSA component calls the resolver mis-placed, not QuickTime's.
