# M1: the target applications in the tab

M1 is done when each target application launches **and is used** in the tab
(a Playwright cell on tools/standalone, the site's library disks,
`~/storage/web-library`): a document made and saved, a build run, a game past
its title screen. This file is the audit: target × System → the cells that
cover it, what they check, the last result.

**launch**: `web/tests/tab_site.mjs` (`executor.web.site.SYSTEM.DISK`): in
front, a window of its own (File > New if none), the second menu drawn when
pressed, still in front with no error alert. Nothing typed, saved, built or
played. **used**: the application did its job (below, Step 2's cells).

Last result: integration run `~/storage/ci/runs/2026-11-01-2153` (site label,
all 7 passed; per-application lines from
`~/storage/executor-grid/m1/w761|w86/*.jsonl`, the same run's
`scoreboard.py tab`). XFAIL: expected to fail by SCOREBOARD.md, so the cell
passes; XPASS: works, the scoreboard behind.
