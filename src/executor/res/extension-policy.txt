# Extensions, control panels and Finder extensions Executor lets run at

# (phase 1, and AppleScript and Finder Scripting from phase 2, of tools/macdecode/inits.yaml, which records why each file is
# where it is). As Extensions Manager does, any other file that runs code
# at startup (INIT, RDEV, fext, appe, AINI, a cdev with INITs or AINIs) is moved into
# "Extensions (Disabled)" / "Control Panels (Disabled)" / "System
# Extensions (Disabled)", and moved back once it is listed. 8.x's control
# panels that are applications ('APPC') run their INITs when listed and
# stay where they are when not. Override per
# data directory with <data_dir>/extension-policy.txt (same format; it
# replaces this list). "System AINI <id>" allows one of the System file's
# 'AINI' resources, which the loader runs before any INIT (-32700 is the
# ASLM Loader, which starts the Shared Library Manager); a file's own
# 'AINI' resources run when the file is allowed. "NAME @ 7.6": allowed only
# on System 7.6 or later (7.5.5's PC Exchange 2.0.5 stays off: STRAGGLERS 62).
# "-NAME": never, whatever the file runs at startup: moved into its folder's
# "(Disabled)" one (Control Strip Modules: "Control Strip (Disabled)") and
# left there.
