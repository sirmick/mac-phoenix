# aevt on Executor (9.0.4's own System) against the G3 (9.0.4): known differences.
# key-glob<TAB>reason. The same as on 8.6 (aevt-executor-8.6.txt); 9.0.4's
# Apple Event Manager answers these as 8.6's does.

layout.new	the return ID, source, interaction level and original address are inline attributes in Executor
layout.put	the same four inline attributes: 64 bytes more, parameters from 154
layout.new.bytes	the parameter offset and attribute count (inline attributes), and the long at 58
coerce.list.one.alis	the alias record an FSSpec coerces to: Executor's NewAlias writes 178 bytes, 9.0.4's 186 (its tagged data)
coerce.null.null	AECoerceDesc of a null descriptor fails on 9.0.4 even to null and ****; Executor answers it (its parameter getters coerce to typeWildCard)
coerce.null.[*]*	the same, to typeWildCard
coerce.obj.want	AEGetParamPtr of a descriptor that is no record ('obj '): 9.0.4 errAENotAERecord (-1704), Executor errAEWrongDataType (-1703)
