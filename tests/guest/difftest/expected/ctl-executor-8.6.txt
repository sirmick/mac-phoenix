# ctl on Executor (8.6 System) against the G3 (8.6): known differences.
# key-glob<TAB>reason. Remove a line when Executor matches (run.py lists those).

# 8.6's popup menu definition speaks the 8.0 messages (features, data
# tags, best rectangle); Executor's popup CDEF doesn't yet (its classic
# CDEF 0 does).
kind.1008.*	popup menu: 8.0 features, data, values (8.6 keeps 0..10 until a menu is set)
kind.*.datasize.font	'font' size per definition (8.6: 4 or none); Executor answers 24 for any data-access control
kind.*.best	best rectangles of 8.x kinds (images, edit text, clock, ...) differ
kind.*.features	features of some 8.x kinds differ
values.16bit	16-bit view of 32-bit values: 8.6 keeps the low word (70000 -> 4464), Executor clamps to 32767

# 8.0 dialogs with the control hierarchy: every item is a control on 8.6
# (static text, edit text, user items too); Executor makes only ctrlItems
# controls.
dialog.root.count*	items as controls: only ctrlItems are controls in Executor
dialog.item.*	static/edit/user items aren't controls in Executor
dialog.appended.7*	static text item isn't a control in Executor
dialog.group.count*	static text item isn't a control in Executor (one fewer embedded)
dialog.Advance.shortened	no focusable control left: the edit text item isn't a control in Executor
