# sys on Executor (8.6 System) against the G3 (8.6): known differences, one key each

gestalt.qd  	QuickDraw's version: Executor answers 32-Bit QuickDraw 1.3 (0x230), 8.6 0x251
gestalt.qdrw	QuickDraw features: colour, deep GWorlds, direct PixMaps (7); 8.6 also grayishTextOr and bits 4-5, which Executor's drawing doesn't have
gestalt.dict	no Dictionary Manager in Executor
gestalt.thds	Thread Manager: present, specific match, ThreadsLib (7); 8.6's bits 3-5 not verified
gestalt.ppc 	no PPC Toolbox in Executor
gestalt.os  	Process Manager attributes: 7.5.5's 0x7FF; 8.6's bits 11-17 not verified
gestalt.ascv	AppleScript is an extension Executor doesn't load
gestalt.ascr	AppleScript is an extension Executor doesn't load
gestalt.fold	Folder Manager: FindFolder (1); 8.x's folder descriptor calls (bit 1) not in Executor
gestalt.fs  	File System attributes: Executor's bits 0-3, 8-9; 8.6's 4-7 (large volumes, extended DiskInit, DT Manager on FSM) not verified
gestalt.fxfr	no Communications Toolbox (File Transfer Manager) in Executor
gestalt.help	Help Manager without Apple Guide (8.6: bit 31)
gestalt.icmp	no QuickTime in Executor
gestalt.otan	Open Transport is Executor's own (opentransport/ot.cpp): its attributes
gestalt.otra	Open Transport is Executor's own: no 'otra'

gestalt.qtim	no QuickTime in Executor
gestalt.shut	Shutdown Manager attributes not verified

gestalt.stdf	Standard File: 58 calls (1); 8.6's translation-aware, colour-icon and bit-4 features not in Executor's
gestalt.strm	no STREAMS (Open Transport's internals) in Executor
gestalt.tbtt	Executor lacks the selector
gestalt.tsmv	Text Services Manager: Executor's has no version to claim
gestalt.wma.	Executor lacks the selector
gestalt.wind	Window Manager 2.0 is there (1); floating windows aren't yet a layer of their own (8.6: 5, bit 2)
gestalt.xttt	Executor's Translation Manager (Easy Open, as on 7.x); the G3's 8.6 has none
gestalt.bugx	Apple's bug-fix flags: the System's patches, not Executor's
gestalt.alis	Alias Manager: 7.5.5's 7; 8.6's 0xB (follows aliases when resolving, not bit 2) not verified
gestalt.romv	no ROM: Executor answers 0x7C on every machine (INITs patch the ROM by its version; the G3: 0x77D)
gestalt.qtvr	no QuickTime VR in Executor
